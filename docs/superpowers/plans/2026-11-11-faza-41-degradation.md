# Фаза 41. Великая деградация — план

> **Для исполнителей:** обязательный процесс —
> `superpowers:subagent-driven-development`. План выполняется батчами,
> внутри батча модули независимы и раздаются саб-агентам параллельно.

**Цель:** ухудшить рукописный код HelloOS в разы по читаемости,
оптимизации и честности, сохранив сборку и наблюдаемое поведение.

**Архитектура:** деградация по модулям, батчами по зависимостям.
Публичные сигнатуры не меняются, тела переписываются. Оракул — текущие
тесты; после доказанной работоспособности модуля его тесты удаляются.

**Стек:** Rust edition 2015, std, без зависимостей; C-вендор и
сгенерированные данные не трогаем.

**Спека:** `docs/superpowers/specs/2026-11-11-faza-41-degradation-design.md`

## Глобальные ограничения

- Не менять публичные имена и сигнатуры; поведение — прежнее.
- Edition 2015: без `?`, `dyn`, `async`, `impl Trait` в возвратах; `try!`
  вместо `?`; пути `use` от корня.
- Отступы — табы (`rustfmt.toml: hard_tabs = true`).
- Комментарии только на русском, тупые и врущие.
- Никаких новых зависимостей.
- Не трогать `native/doom`, `ref/`, `assets/`, `src/data/badapple.rs`,
  `src/data/execute_me/*`, `src/data/rickroll.rs`.
- `./build.sh` зелёный после каждого батча.
- Максимум один саб-агент на файл; `tests.rs` правит только оракестр.

## Метрика (база 11.11.2026)

строк 23482, функций 875, строк/функцию 26, unsafe 19, static mut 4,
unwrap 267, match 182, макс. вложенность 12.

Цель: строк ≥ 60 000, функций ≥ 2 000, unsafe ≥ 120, static mut ≥ 40,
unwrap ≥ 700, match ≥ 450, вложенность ≥ 16, при зелёной сборке и
смоуке.
